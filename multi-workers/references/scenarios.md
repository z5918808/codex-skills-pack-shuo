# Maintenance scenarios

Static checks; do not create tasks for skill maintenance.

- Small or serial execution: existing Terra continues; no extra Worker and no Main takeover merely because the task is small.
- Hard planning or diagnosis: Main decides, then Terra executes; no automatic effort/model change.
- Useful independent branches: ask once before expansion; current authorized DUO work continues while awaiting the answer. Declining keeps the original Worker.
- Already approved split: reuse goal-scoped approval and the shared cap/lifecycle; safely reconcile A before changing it from execution to aggregation.
- No existing DUO: identify the intended run; do not start a single-agent mode, nested controller or subagent substitute.
- Approved execution: apply the shared DAG/relay fixtures, preserving source evidence, write ownership, stop and Main acceptance.
