# Bolder

Use the project design context from `impeccable`; this skill changes emphasis, not product scope.

## Core Rule

Make one thesis unmistakable. Boldness comes from decisive hierarchy and contrast, not more effects.

1. Identify the weak focal point and the brand’s acceptable risk.
2. Choose one amplification lane: scale, typography, composition, color, imagery, or motion.
3. Increase contrast between primary and secondary elements; do not make everything loud.
4. Preserve readability, task completion, accessibility, and performance.
5. Reject generic glow, glass, gradient text, random texture, and animation when they replace a real concept.

Verify the focal point at a glance, then test mobile, long content, reduced motion, and the primary task. Revert any flourish that competes with the task.
