# Heavy Duo

Use for explicit Heavy Duo or its duo-brainer alias. Read [Conditional Duo](../duo-run/SKILL.md) and follow its lifecycle, authority, return and acceptance contracts. Every execution invocation runs required decision gate process（主機 `18_conditional_gate_process.md`，本包未附）; conditional routing（主機 `17_conditional_collaboration.md`，本包未附） is the single allocation policy. Skill maintenance starts no task.

Default: Terra/medium for sustained implementation and huge data digestion, GPT-6.1 Sol/medium for Main planning, diagnosis and review; a separate Sol reviewer defaults to medium. A triggered Astra advisor or explicitly selected Astra Main defaults to high under the shared route; preserve an actual selected effort. Short judgment-heavy work may stay with Sol; low-risk deterministic work may stay with Terra when its actual activation/acceptance route permits. Sol takes only a bounded repair/judgment slice from a long run and then hands execution back to Terra.

Astra is a bounded decision advisor only after the shared gate triggers. Do not automatically pair Sol with Astra, assign all planning to Astra or create a third coordinator. A current explicit request for a fixed Sol/Astra pair is a task-specific override; preserve it and the user's actual Main setting without making it the default again. Its roles and evidence must be explicit, not inferred from this legacy name.

Implementation requests permit scoped local implementation and meaningful tests, with one writer per resource. Research-only requests remain read-only. Neither model strength nor a handoff grants live authority, worktrees or destructive actions. Reviewer begins with requirements, diff, tests and report, expands for concrete gaps, and verifies the actual outcome. No mandatory opening ceremony, per-step approvals, wait loops, duplicate investigation or analysis-only role masquerading as implementation.

Validate maintenance with the shared routing-gate tests and Duo's applicable semantic scenarios. Do not launch tasks to test an instruction edit.
