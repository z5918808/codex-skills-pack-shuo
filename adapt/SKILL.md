# Adapt

Use the project design context from `impeccable`; this skill adds adaptation judgment only.

## Core Rule

Adapt the task, hierarchy, and interaction to the target context. Do not merely scale the desktop layout.

1. Identify source assumptions: space, input, bandwidth, attention, and platform conventions.
2. Identify target constraints and the primary user task.
3. Preserve critical capability; reprioritize, reflow, or progressively disclose secondary content.
4. Replace hover-only, pointer-only, or wide-screen interactions with target-appropriate behavior.
5. Use content-driven breakpoints and existing tokens before inventing device categories.

Do not hide core functionality, change information architecture without reason, or assume desktop means fast and mobile means simple.

Verify representative widths, orientation, zoom, keyboard, touch, pointer, long content, slow loading, and one real target device when available.
