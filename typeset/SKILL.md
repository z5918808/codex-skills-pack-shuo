# Typeset

Use the typography and product context from `impeccable`; improve the type system, not decoration.

1. Inventory semantic roles, languages, content ranges, and existing tokens.
2. Choose fonts for voice, readability, glyph coverage, licensing, and loading cost.
3. Use the fewest sizes and weights that create an unmistakable hierarchy.
4. Set measure, line height, tracking, and numeric features from the actual font and content.
5. Provide metric-compatible fallbacks and load only required files or subsets.
6. Preserve zoom, user font settings, and responsive reflow.

Do not ban common fonts, require multiple families, force a fixed modular ratio, or apply universal 16px/65ch/rem rules regardless of context. Dense data, long-form reading, marketing, and multilingual UI need different systems.

Verify at 200% zoom, narrow and wide layouts, long translations, missing glyphs, font-loading failure, tabular data, contrast, and layout shift.
