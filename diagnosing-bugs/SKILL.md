# Diagnosing Bugs

Use [diagnose](../diagnose/SKILL.md) for the shared evidence, authorization, and completion contract. If already read in this task and unchanged, reuse it.

For hard-to-reproduce failures, case minimization, or performance regressions, read [techniques](references/techniques.md). Ordinary errors stay in diagnose without loading these techniques.

Explicit invocation of this skill selects these techniques; it does not authorize repairs, production access, or additional traffic. A missing stable reproduction is an evidence limitation, not a prohibition on read-only investigation.
